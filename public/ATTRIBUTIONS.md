# Attributions

All art, sound, and music in Project Hop are original to this project.

- **Sprites** are drawn in code (`src/render/sprites.ts`) and icons are generated as original
  PNG files in `public/icons/`.
- **Sound effects and music** are synthesised in the browser with the Web Audio API
  (`src/audio/audio.ts`, `src/audio/music.ts`). No audio files are shipped.
- **Fonts** use the system font stack. No font files are shipped.
- **Third-party code** is limited to build tools and libraries listed in `package.json`.
  No third-party game assets are used.

No licensed assets are in use as of this release. If one is added, list it here with its
source, licence, and any required credit text before release (Constitution Principle V).
